🛠 Supabase Setup Required

To enable email login and content, connect this app to your free Supabase project.

Step 1: Go to supabase.com and create a free project.

Step 2: In your project dashboard, go to Settings → API and copy your Project URL and anon public key.

Step 3: Open this HTML file in a text editor and replace the two placeholders near the top of the script.

Step 4: Run the SQL from the comment near the top of the script in your Supabase SQL Editor.
