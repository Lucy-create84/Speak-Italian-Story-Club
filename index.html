Format: one line per spoken line. Start a line with a timestamp like [0:15] or [0:15.4] so the pencil follows the narration precisely (without one, lines are spaced evenly). The Sync button below the text field writes them for you.
Missing word: wrap it in curly braces, e.g. {cuore}. For A1/A2 texts it becomes multiple choice automatically (or list your own options with {cuore|amore|casa|sole}, correct word first). For B1/B2 it's always typed. Only enter text you have the rights to use, or that you wrote yourself.
Tip for A1/A2: write your own options with words of the same type as the answer (a verb among verbs), otherwise learners can guess by elimination. B1/B2 answers must have the correct accent.
